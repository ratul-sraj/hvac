# Sample drawing credits

The floor plans LoadLens ships as samples are somebody else's drawings. Each is used under its licence,
and this file records the credit so it is never lost. There are currently two licensed plans (plus one
synthetic test fixture, described at the end).

### What that means

- **Attribution** — we name the author (Vivianwwj), the file (LEVEL 11 FLOOR PLAN.pdf) and the
  licence (CC BY-SA 4.0). The credit appears in the plan panel (section 3) of `app.html`, in the
  "Sample drawing credit" section of `about.html`, and here.
- **Share-alike** — the share-alike term applies to the *file itself*: the drawing remains CC BY-SA
  4.0. LoadLens ships the unmodified file and does not relicense it. LoadLens' own source code is
  separate and is not affected.
- **No endorsement** — the author has not endorsed LoadLens; the drawing is simply reused within the
  terms of the licence.
- **Honesty about what it is** — the plan prints room *names* but no room *areas*. LoadLens therefore
  reports those rooms with their areas unknown and leaves them out of the cooling load until the user
  sets each area. Nothing about the demonstration invents a load.

### Where the file is used

- **Served sample**: `samples/level-11-floor-plan.pdf` — this is what `Try sample drawing` loads by
  default (`js/app.js`, `SAMPLE_REAL`).
- **Deploy allow-lists**: `infra/50-deploy-site.sh` and `.github/workflows/pages.yml` list it by name
  so it is published to `/samples/` — the allow-list exists precisely so a *private* drawing can never
  be published, so this one public file is named explicitly.

### Not to be confused with the test fixture

`tests/samples/sample-plan.pdf` is a different, **synthetic** drawing (generated by
`tools/make-sample-plan.mjs`). It stays as the deterministic test fixture and is loaded through the
unadvertised `?sample=synthetic` hook (e.g.
`app.html?sample=synthetic`), not by the default button. It is not the drawing credited above.

### What that means

- **Attribution** — we name the author (MichaelScott99), the file (BALLARAT Waller Estate Floor plan.pdf)

- **Share-alike** — the share-alike term applies to the *file itself*: the drawing remains CC BY-SA 3.0.

- **No endorsement** — the author has not endorsed LoadLens; the drawing is simply reused within the

- **Why it is here** — this is a cellular house layout (a wall between the rooms), the kind of drawing

  uses, against **21 of 56 (38%)** on the open-plan LEVEL 11 office sample. It is staged so the demo can
  show a layout that auto-fills well.

  it is published to `/samples/` once it is used — the allow-list exists precisely so a *private* drawing
